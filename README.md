## Getting Started

### Install Tools and Dependencies

To build and run the tutorials, first install these tools.

- [CMake](https://cmake.org)
- [clang](https://clang.llvm.org/) or [gcc](https://gcc.gnu.org/) — A C++ compiler that supports C++20
- [make](https://www.gnu.org/software/make/) or [ninja](https://ninja-build.org/)
- [glfw](https://docs.vulkan.org/tutorial/latest/02_Development_environment.html#_glfw_2)
- [glm](https://docs.vulkan.org/tutorial/latest/02_Development_environment.html#_glm_3)
- [Vulkan SDK](https://docs.vulkan.org/tutorial/latest/02_Development_environment.html#_vulkan_tarball)
